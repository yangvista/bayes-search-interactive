# 没找到，然后呢？｜一次搜索失败之后的贝叶斯更新

《概率论与数理统计》课程叙事网页：以「找耳机」的搜索失败为线索，用贝叶斯公式讲清
「没找到 ≠ 不在」，并以 **350 份问卷**（前测 → 交互演示 → 后测）的真实数据作为证据。

## 预览

无任何构建依赖，二选一：

```bash
# 方式一：带 no-cache 响应头的开发服务器（改完即刷即见）
python serve.py 8123        # → http://127.0.0.1:8123

# 方式二：直接双击 index.html（纯静态，离线可用）
```

## 文件结构

```
index.html        页面结构
style.css         全部样式（油画背景、笔刷换画、章节排版）
story.js          全部交互逻辑（开场搜索对话 / 可能世界 / 滚动叙事 / 计算器 / 策略板 / 问卷可视化）
data.js           350 份问卷逐人数据（由问卷星导出 CSV 生成）
*.webp            六张章节油画背景 + 耳机特写（由 src-paintings 原图压缩而来）
serve.py          开发服务器（Cache-Control: no-store）
analyze.mjs       问卷数据统计脚本（生成叙事所用的全部数字）
build_data.mjs    CSV → data.js 生成脚本
```

`src-paintings/` 为油画原图（约 30MB），未入库；`.mimosa/` 为本地工具产物，未入库。

## 数据口径

- 问卷共 350 份；前测 → 交互演示 → 后测的配对设计。
- 数值题未作答按缺失处理（原始记录以 999 标记）。
- 演示参数为教学设定：先验 图书馆 40% / 教室 25% / 食堂 35%，检出率 70%（食堂 40%）。
- 理论后验：P(在图书馆∣失败) = 0.40×0.30 ÷ 0.72 = **16.67%**。
