# 没找到，然后呢？｜一次搜索失败之后的贝叶斯更新

《概率论与数理统计》课程叙事网页。以「校园里找耳机」的一次搜索失败为线索，讲清楚一个课本结论：**「没找到」不等于「不在」，它只是把概率变小了**——并把这个结论交给数据检验：我们收集了 **350 份问卷**（做题 → 看交互演示 → 再做题），用前后测的真实数字作证。

**在线观看**：<https://yangvista.github.io/bayes-search-interactive/>

## 页面讲了什么

| 章节 | 内容 |
|---|---|
| 序 | 耳机不见了。图书馆翻了一遍，没有找到——这个念头对吗？ |
| 第一部分 · 没找到，等于不在吗 | 用 100 个方格展示「失败削弱可能，但不消灭可能」 |
| 第二部分 · 失败如何改写答案 | 先验、检出率、全概率、贝叶斯公式四步，配可调参数计算器 |
| 第三部分 · 然后去哪里找 | 「最可能」不等于「最该先搜」，最优策略看概率与把握的乘积 |
| 第四部分 · 350 份问卷的证据 | 前后测对比、估计分布、策略迁移、逐份答卷与难点归因 |
| 尾声 | 你的直觉和 350 人对答案；公式速查与术语表 |

## 本地运行

不需要安装任何东西，两种方式任选：

```bash
# 方式一：用 Python 起一个本地服务器（推荐，改动立即生效）
python serve.py 8123        # 然后浏览器打开 http://127.0.0.1:8123

# 方式二：直接双击 index.html，离线也能完整运行
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `style.css` | 全部样式：油画背景、笔刷换画、章节排版 |
| `story.js` | 全部交互：开场搜索对话、方格演示、滚动叙事、参数计算器、策略板、问卷图表 |
| `data.js` | 350 份问卷的逐人数据（由问卷星导出表格生成） |
| `cover-night.webp` 等 7 张图 | 各章节油画背景与耳机特写 |
| `serve.py` | 本地开发服务器（禁用缓存，改完刷新即可） |
| `analyze.mjs`、`build_data.mjs` | 问卷数据的统计与转换脚本，页面上的每个数字都能追溯到原始表格 |

油画原图约 30MB，放在本地 `src-paintings` 文件夹，未上传仓库。

## 数据口径

- 问卷共 **350 份**：正在学习 181 人、已经学过 102 人、尚未学习 67 人；问卷星匿名作答。
- 流程：知情同意 → 前测 → 交互演示 → 后测 → 迁移题。
- 数值题未作答按缺失剔除（原始记录用 999 标记）。
- 演示参数为教学设定：先验 图书馆 40%、教室 25%、食堂 35%；检出率 图书馆 70%、教室 70%、食堂 40%。
- 理论后验：P(在图书馆∣失败) = 0.40×0.30 ÷ 0.72 = **16.67%**。
- 局限：方便样本、自愿参与、前后测非随机对照，数字用于教学演示。
