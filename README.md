# 没找到，然后呢？｜一次搜索失败之后的贝叶斯更新

**在线观看**：<https://yangvista.github.io/bayes-search-interactive/>

---

## 一、这是一个讲什么的页面？

一句话：**用「找耳机」这件小事，把《概率论与数理统计》里最重要的公式——贝叶斯公式——讲成一个可以动手玩、并被 350 份真实问卷验证的故事。**

整条内容线是这样的：

> 周三晚上，你的耳机不见了。你最后一次确定戴着它是在图书馆，于是折回去翻了一遍——8 分钟，一无所获。走出馆门时你冒出一个念头：**「看来根本就不在图书馆。」**
>
> 这个念头对吗？这门课的答案是：**它只对了一半。**「没找到」削弱了「耳机在图书馆」的可能，但远没有把它变成零——因为搜索本身不完美（检出率只有 70%）。
>
> 用贝叶斯公式把这次失败算一遍：耳机在图书馆的先验概率 40%，在图书馆且没找到的概率 0.4×0.3=0.12，失败的总概率 0.72，于是后验
> **P(在图书馆∣失败) = 0.12 ÷ 0.72 = 16.67%**。
>
> 概率更新之后，搜索就变成了排序问题：按「在每一处的概率 × 在那里找得到的把握」决定下一站。最后，我们把这套机制给 **350 位同学**实测了一遍：做题、看演示、再做一遍——用他们前后测的数据回答一个问题：**这门课，真的能改变人的直觉吗？**

页面全程可以动手：替自己搜一次耳机、亲手把 100 个「可能世界」变稀、拖动参数看后验如何回应、在策略板上一次次失败着搜索，最后在 350 份答卷里对上你自己的答案。

## 二、核心数据发现（全部来自真实问卷，N = 350）

| 发现 | 数字 |
|---|---|
| 直觉并非全错：前测就有多数人知道「失败 ≠ 不在」 | 72.6% |
| 但能把「还剩多少」估到计算区间（14%–19%）的只有 | 20.3% |
| 看完交互演示后，这一比例升至 | **36.3%** |
| 完整完成演示的人 vs 未完成的人，落在计算区间的比例 | 41.7% vs 17.7%（2.4 倍） |
| 答对「不能说明」的人从前测到后测 | 72.6% → 88.0% |
| 看懂「最可能 ≠ 最该先搜」后，再搜地点集中到教室 | 55.7%（前测仅分散在食堂/教室） |
| 答题者自述最难的一步 | 「失败后如何重算概率」（36.3%）——恰是贝叶斯公式本身 |

一句话结论：**直觉对了一半，缺的是把直觉换成数字的那一半——而这正是交互演示能补上的部分。**

## 六、数据口径与局限

- 问卷共 **350 份**：正在学习 181 人、已经学过 102 人、尚未学习 67 人；问卷星匿名作答。
- 流程：知情同意 → 前测 → 交互演示 → 后测 → 迁移题。
- 数值题未作答按缺失剔除（原始记录用 999 标记）。
- 演示参数为教学设定：先验 图书馆 40%、教室 25%、食堂 35%；检出率 图书馆 70%、教室 70%、食堂 40%。
- 局限：方便样本、自愿参与、前后测非随机对照，数字用于教学演示，不构成严格因果推断。
